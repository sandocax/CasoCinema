# Requisitos Funcionais

### RF01 - Manter Cadastro de Filmes
O sistema deve permitir o registro de filmes, incluindo título, gênero, diretor, elenco e duração.

### RF02 - Gerenciar Sessões
O sistema deve permitir a criação e o agendamento de sessões de cinema, vinculando um filme a uma sala e horário específicos.

### RF03 - Registrar Público
O sistema deve permitir a inserção da quantidade de espectadores presentes em cada sessão após sua realização.

### RF04 - Consultar Programação
O sistema deve permitir a busca de filmes e sessões disponíveis por cinema, cidade ou gênero.

### RF05 - Gerar Relatórios de Público
O sistema deve totalizar e exibir o público acumulado por sessão, por filme e por unidade do cinema.
